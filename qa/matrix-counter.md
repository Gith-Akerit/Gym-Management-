# Test matrix — แอปเคาน์เตอร์ (KENC-20)

เขียนใหม่ทั้งชุดสำหรับโจทย์ที่เปลี่ยนที่ commit `cf6fa58` แทน matrix เดิมของ Phase 1–3
ซึ่งครึ่งหนึ่งทดสอบแอปสมาชิกที่ถูกลบไปแล้ว

**ขอบเขต** — ระบบนี้มีผู้ใช้สองบทบาทเท่านั้นคือ **พนักงาน** และ **ผู้ดูแลระบบ** สมาชิกไม่มีบัญชี
ไม่มีอีเมล ไม่ล็อกอิน สิ่งที่สมาชิกถือคือ **รูปบัตร** หนึ่งใบในแชต

**สถานะ** — `รันแล้ว` คือมีผลจริงจากชุดทดสอบในเครื่อง dev · **เครื่องจริง `170ee35` ✓** คือพิสูจน์บน https://srv1979069.hstgr.cloud แล้ว ·
`รอ UI` คือต้องรอทีมพัฒนาใส่หน้าตาตามแบบ 2 ก่อน ·
`อุปกรณ์จริง` คือพิสูจน์ด้วยซอฟต์แวร์แทนไม่ได้ ต้องทำบนกล่องหรือบนอุปกรณ์จริง
