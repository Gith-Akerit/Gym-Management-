มี 6 เครื่อง · 1 โปรแกรม · 3 บทความ · ข้อความความปลอดภัย · รายการรูปที่ยิมต้องถ่าย

## โครงสร้าง

| คีย์ | คืออะไร |
|---|---|
| `meta.visibility_rule` | ใครเปิดดูได้ — `machines` และ `articles` เป็น **สาธารณะ** (QR บนเครื่องต้องใช้ได้เสมอ) · `programs` และหน้าแรก **เฉพาะสมาชิกที่ยังไม่หมดอายุ** |
| `safety` | ข้อความความปลอดภัย 3 ชุด: หน้าแรกพอร์ทัล · ท้ายหน้าเครื่อง · ก่อนเริ่มโปรแกรม |
| `machines[]` | เครื่องละหนึ่งรายการ ดูช่องด้านล่าง |
| `programs[]` | โปรแกรม "เริ่มต้น 4 สัปดาห์" พร้อมสถานีเรียงลำดับ |
| `articles[]` | บทความเทคนิค 3 เรื่อง `body` เป็น array ของย่อหน้า |
| `photo_shotlist` | รายการรูป 6 ภาพที่ยิมต้องถ่าย พร้อมสเปกและชื่อไฟล์ |

### ช่องของ `machines[]`

`code` · `name_th` · `name_en` · `type` (`cardio` / `strength`) · `muscles[]` · `photo{file,status}` · `setup` · `steps[]` (5 ข้อ) · `cautions[]` (3 ข้อ) · `weight_howto` **หรือ** `intensity_howto` (เครื่องคาร์ดิโอใช้ตัวหลัง) · `video{url,title,channel,lang,kind}` · `reviewed_by` · `reviewed_at`

**ไม่มีช่องน้ำหนักเป็นตัวเลข** ตามที่ตกลงกันไว้ — ใช้ `weight_howto` ซึ่งเป็นวิธีหาน้ำหนักด้วยตัวเอง ใช้ได้กับทุกคนทุกเครื่องโดยไม่ต้องให้เทรนเนอร์กรอกตัวเลขเพิ่ม

### ช่องของ `programs[].stations[]`

`order` · `machine` (อ้าง `machines[].code`) · `role` · `sets` / `reps` / `rest` (ท่าแรงต้าน) หรือ `duration` (คาร์ดิโอ) · `note`

**`values_are_examples: true`** อยู่ที่ระดับโปรแกรม — หน้าจอควรแสดงป้ายว่าเป็นค่าตัวอย่างที่เทรนเนอร์ปรับได้ จนกว่า `reviewed_by` จะถูกกรอก

## สิ่งที่ต้องทำก่อนขึ้นระบบจริง

1. **รูปเครื่อง 6 ภาพ** — ยังไม่มี ทุกรายการเป็น `status: "ยังไม่มี — ยิมถ่าย"` · สเปกและชื่อไฟล์อยู่ใน `photo_shotlist`
2. **เทรนเนอร์ตรวจตัวเลขในโปรแกรม** แล้วกรอก `reviewed_by` / `reviewed_at` ของ `P-START`
3. **เจ้าของยิมอนุมัติข้อความความปลอดภัย** แล้วกรอก `safety.approval.approved_by` / `approved_at` — ข้อความชุดนี้เขียนตามที่ตัดสินไว้แล้ว รวมบรรทัด "อายุต่ำกว่า 18 ปีให้ปรึกษาพนักงานก่อนเริ่ม"
4. **ตรวจชื่อช่องของวิดีโอ M-06** — อีก 5 คลิปเป็นซีรีส์ "สอนใช้เครื่องออกกำลังกาย … BY.โค้ชปูแน่น" ของช่อง REALGYM ส่วน M-06 มาจากอีกช่องหนึ่ง ระบุชื่อช่องให้ครบก่อนขึ้นระบบ

## เรื่องวิดีโอ

ทุกคลิปเป็น **ลิงก์ YouTube สาธารณะของช่องอื่น** ไม่ใช่ของยิม — ตรวจแล้วว่าเปิดได้และชื่อคลิปตรงกับเครื่อง ณ วันที่ 16 กันยายน 2569

ข้อจำกัดที่ต้องรู้: **คลิปของช่องอื่นถูกลบหรือปิดเมื่อไรก็ได้** จึงควร (ก) ให้หน้าจอรองรับกรณีคลิปเปิดไม่ได้โดยไม่พังทั้งหน้า และ (ข) เมื่อยิมถ่ายคลิปของตัวเองครบแล้ว ให้แทนที่ทีละเครื่องโดยแก้เฉพาะช่อง `video` · การฝังเป็นภาพนิ่ง + ปุ่มเล่นตามที่ Designer กำหนด ทำให้การเปลี่ยนลิงก์ไม่กระทบอย่างอื่น

5 ใน 6 คลิปเป็นซีรีส์สอนใช้เครื่องของช่องเดียวกัน จึงมีวิธีอธิบายและลำดับใกล้เคียงกัน ซึ่งช่วยให้สมาชิกไม่สับสนเมื่อดูหลายเครื่องต่อกัน

## ที่ยังไม่ได้ทำในชุดนี้

- เครื่องที่เหลือ (อีก 8 เครื่องจากรายการ 14 เครื่อง) และโปรแกรมอีก 3 แบบ — รอชุดเริ่มต้นนี้ผ่านการใช้งานจริงก่อน
- คลิปวิดีโอของยิมเอง — ถ่ายพร้อมรูปเครื่องได้ในรอบเดียวกัน
- บทความเทคนิคอีก 5 เรื่องจากรายการ 8 เรื่องในแผน
